# Logo Placeholder

This file serves as a placeholder for the project logo.

**Expected file:** `logo.png` or `logo.svg`
**Dimensions:** 512x512px (minimum)
**Format:** PNG with transparency or SVG

The logo will be generated using Sora AI based on the prompt provided.

## Usage
Once generated, replace this file with:
- `logo.png` - Main logo file
- `logo-small.png` - Smaller version for headers (64x64px)
- `logo.svg` - Vector version for scalability
